# 레슨 6 - 에이전트가 볼 수 있는 내용 파악하기

Copilot은 대화 기록, 읽은 파일, 프로젝트 지침 등을 참고해 작업합니다. 이 정보를 담는 공간을 **컨텍스트 윈도우(Context window)** 라고 합니다. 사용량을 확인하고, 필요할 때 대화를 정리하는 방법을 익힙니다.

**이 레슨에서 할 일**

- `/context`로 컨텍스트 사용량을 확인합니다.
- `/compact`와 `/clear`의 차이를 이해합니다.

> 이 레슨의 명령은 별도 안내가 없으면 **Copilot CLI 입력창**에 입력합니다. 터미널에서 실행하는 명령은 "터미널에서"라고 표시합니다.

---

## 6-1. 현재 작업 세션의 사용량 확인

**레슨 5의 워크트리 세션**에서 실행합니다.

```text
/context
```

항목별 사용량과 남은 공간을 확인합니다. 이 화면은 컨텍스트의 **구성과 사용량**을 보여 주며, 모든 파일과 대화 내용을 그대로 나열하지는 않습니다.

> 이 세션은 레슨 7·8에서 계속 사용하므로 **여기서는 `/clear`를 실행하지 않습니다.**

## 6-2. 언제 무엇을 쓰나

| 명령 | 동작 | 사용 시점 |
| --- | --- | --- |
| `/context` | 사용량 확인 | 응답이 느려지거나 맥락을 놓친다고 느낄 때 |
| `/compact` | 대화 기록을 요약해 공간 확보, 작업 맥락은 유지 | 같은 작업을 계속하면서 공간을 줄일 때 |
| `/clear` | 새 대화 시작 | 다른 주제로 새로 시작할 때 |

- 대화가 토큰 한도에 가까워지면 Copilot CLI가 자동으로 압축합니다.
- `/clear` 후에도 기본 지침과 도구 정보는 남으므로 사용량이 0이 되지는 않습니다.
- `/clear`는 대화만 초기화하며 **수정한 파일을 되돌리지 않습니다.**
- 새 대화를 시작했다면 이슈 번호, 관련 파일, 원하는 작업을 다시 알려 줍니다.

## 6-3. 직접 비교해 보기 (새 세션에서)

현재 작업 세션을 보존하기 위해 **새 세션**을 열어 실험합니다. (사이드 패널 **Sessions** 탭 → `n`)

1. `/context`로 상태를 확인합니다.
2. 다음을 요청합니다.

   ```text
   @index.html 코드에 대해 일목요연하게 테이블 형식으로 설명해줘.
   ```

3. `/context`로 다시 확인해 1번과 비교합니다.
4. `/compact`를 실행합니다.
5. `/context`로 다시 확인해 3번과 비교합니다.
6. `/clear`를 실행한 뒤 `/context`로 확인해 비교합니다.
