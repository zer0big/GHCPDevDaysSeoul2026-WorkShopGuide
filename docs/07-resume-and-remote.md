# 레슨 7 - 세션 재개 및 원격 이용

이전 대화를 다시 설명하지 않고 작업을 이어가는 방법을 익힙니다.

**이 레슨에서 할 일**

- CLI를 종료한 뒤 이전 작업 세션을 재개합니다.
- `/resume`으로 CLI 안에서 세션을 전환합니다.
- (선택) 다른 기기에서 로컬 세션에 접속합니다.

> 이 레슨의 명령은 별도 안내가 없으면 **Copilot CLI 입력창**에 입력합니다. 터미널에서 실행하는 명령은 "터미널에서"라고 표시합니다.

---

## 7-1. 종료 후 재개하기

1. 입력창에 `/exit` 를 입력해 CLI를 종료하고 터미널로 돌아갑니다. (`/quit` 또는 `Ctrl+C` 두 번도 같습니다.)

   > `/exit` 는 Copilot CLI 슬래시 명령입니다. `!` 로 들어간 셸 안에 있을 때는 `exit` 로 셸을 먼저 빠져나와야 CLI 입력창으로 돌아옵니다.
2. 터미널에서 실행합니다.

```bash
copilot --resume
```

3. 목록에서 **레슨 5에서 문항 섞기를 구현한 세션**을 선택하고 Enter를 누릅니다.
4. 이전 대화와 작업 폴더·브랜치가 맞는지 확인합니다. 모델도 확인하고, 필요하면 `/model`로 다시 선택합니다.

> 세션 재개는 저장된 대화를 이어가는 기능입니다. 파일을 이전 버전으로 되돌리지 않습니다.

## 7-2. CLI 안에서 세션 전환

```text
/resume
```

목록에서 원하는 세션을 선택하고 Enter를 누릅니다. 다음 레슨은 **문항 섞기를 구현한 워크트리 세션**에서 이어갑니다.

## 7-3. (선택) 다른 기기에서 접속

계정에서 원격 기능을 사용할 수 있으면 다음 명령으로 상태를 확인하고 켭니다.

```text
/remote
/remote show
/remote on
```

화면 안내에 따라 웹이나 GitHub Mobile에서 접속합니다. **로컬 컴퓨터와 CLI는 계속 실행 중이어야 합니다.**

> `/remote`는 로컬에서 실행 중인 세션에 원격으로 접속하는 기능입니다. 작업을 클라우드에 맡기는 `/delegate`(레슨 9)와는 다릅니다. 이번 실습에서는 건너뛰어도 됩니다.
