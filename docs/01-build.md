# 레슨 1 - 터미널에서 퀴즈 만들기

하나의 상세한 요청으로 프로젝트 전체를 만들고, 승인하기 전에 에이전트의 제안을 검토합니다. 그런 다음 범위를 한정해 작은 변경을 한 가지만 적용합니다.

**이 레슨에서 할 일**

- 외부 의존성이 없는 `index.html` 한 파일로 퀴즈를 만듭니다.
- 같은 세션에서 퀴즈를 브라우저로 엽니다.
- 범위를 한정해 한 가지만 수정하고 결과를 확인합니다.

> 이 레슨의 명령은 별도 안내가 없으면 **Copilot CLI 입력창**에 입력합니다. 터미널에서 실행하는 명령은 "터미널에서"라고 표시합니다.

---

## 1-1. 퀴즈 만들기

Copilot CLI 입력창에 아래 프롬프트를 붙여 넣고 Enter를 누릅니다.

```text
10개의 문항, 진행률 표시줄, 점수 카운터, 다채로운 애니메이션 피드백(정답 시 녹색, 오답 시 빨간색으로 흔들림)이 포함된 우주 탐사 퀴즈를 만들어 주세요. 마지막에는 이모지 반응이 포함된 결과 화면을 표시해 주세요. index.html 파일 하나로 구성하고, 서버나 외부 의존성은 사용하지 마세요. 접근성이 뛰어나고 키보드만으로 탐색할 수 있어야 하며, prefers-color-scheme 설정에 따라 라이트/다크 모드를 지원해 주세요.
```

에이전트가 작업 폴더를 확인하고 구현 계획을 세운 뒤 파일 생성 승인을 요청합니다.

## 1-2. 승인 요청 읽고 선택하기

| 상황 | 선택 |
| --- | --- |
| `index.html` 파일 생성·수정 승인 | **2번** - 이 세션 동안 이 실습 폴더의 파일 작업은 다시 묻지 않습니다 |
| 문법 검사 등 명령 실행 승인 | **1번 Yes** - 이번 한 번만 허용합니다 |
| 의도하지 않은 작업으로 보일 때 | **3번 No** - 취소하고 원하는 방향을 입력합니다 |

> 2번은 "그 도구를 이 세션 동안 어떤 방식으로든 다시 묻지 않고 사용"하도록 허용합니다. 신뢰하는 실습 폴더 안의 파일 작업이기 때문에 2번을 선택하는 것입니다.

## 1-3. 브라우저에서 열기

완료 메시지가 나오면 Copilot CLI 입력창에서 운영체제에 맞는 명령을 실행합니다.

| OS | 명령 |
| --- | --- |
| Windows | `!start index.html` |
| macOS | `!open index.html` |
| Linux | `!xdg-open index.html` |

몇 문제를 풀어 보고 키보드(Tab, Enter, Space)로도 조작해 봅니다.

## 1-4. 작은 변경을 적용하고 확인하기

범위를 한정한 요청이 어떻게 동작하는지 확인합니다.

```text
결과 화면이 밋밋해 보입니다. 퀴즈를 완주했다는 느낌이 더 잘 드러나도록, 최종 점수까지 숫자가 올라가는 애니메이션을 추가하고 이모지 반응을 더 크게 표시해 주세요. 이 두 가지 외에는 아무것도 변경하지 마세요.
```

1. 브라우저에서 페이지를 새로 고침한 뒤 퀴즈를 끝까지 풀어 결과 화면을 확인합니다.
2. 아직 Git 커밋이 없으므로 이전 버전과 비교할 기준이 없습니다. 레슨 3에서 첫 커밋을 만든 뒤부터 `/diff`로 비교할 수 있습니다.
